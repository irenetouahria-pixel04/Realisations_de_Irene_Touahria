# Projet Séries Temporelles

Projet d’économétrie des séries temporelles réalisé de décembre 2025 à janvier 2026, lors de mon M1 MBFA.

## Objectif
Étudier la substitution du pétrole par les énergies renouvelables à partir de données financières et énergétiques.

## Données
- Brent
- S&P Global Clean Energy

## Méthodes
- Exploitation et nettoyage des bases de données
- Création de séries temporelles
- Calcul de rendements logarithmiques
- Statistiques descriptives
- Tests économétriques
- Modélisation ARIMA
