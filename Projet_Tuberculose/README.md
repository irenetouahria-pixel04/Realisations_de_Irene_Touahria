# Projet Tuberculose

Projet d'analyse de données en R réalisé de mars à mai 2025 à partir de la base Tuberculosis Burden by Country de l'OMS.

## Outils
- R
- ACP
- Clustering hiérarchique
- K-means

## Contenu
- rapport du projet en zip, pour y avoir accès, il faut appuyer sur affichier le code brut puis le document zip devrait se télécharger sur vos ordinateurs
- fichier Rmd
- Base de données TB_Burden_Country.csv
